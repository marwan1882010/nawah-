# Nawah 🌿

موقع نباتات بسيط جاهز للنشر على GitHub Pages.

## الملفات
- index.html
- style.css
- script.js

## التشغيل
افتح `index.html` في المتصفح.

## GitHub Pages
ارفع الملفات الثلاثة إلى Repository، ثم:
Settings → Pages → Deploy from a branch → main → / (root)

## مهم
غيّر رقم واتساب الموجود في `index.html` و `script.js` إلى رقمك قبل النشر.
